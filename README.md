# Insurance Business Intelligence Platform

## 📌 Project Overview

This project is the **final outcome of my internship**. It consolidates all the work completed throughout the internship into a single web application, providing a centralized platform that simplifies access to business intelligence tools, dashboards, reports, and AI-powered features.

The goal of this platform is to improve efficiency by replacing multiple separate tools with one intuitive interface, allowing users to access information more quickly and make informed decisions based on real-time data.

---

# 🎯 Objectives

The main objectives of this project are to:

- Centralize all internship deliverables into one platform.
- Simplify access to business intelligence reports and dashboards.
- Improve the user experience through an intuitive interface.
- Facilitate faster and more efficient decision-making.
- Integrate artificial intelligence to assist users in querying and analyzing business data.

---

# 🚀 Features

## 📊 Business Intelligence Dashboards

The platform integrates several interactive Power BI dashboards, including:

- Sales Dashboard
- Claims Dashboard
- Cancellations Dashboard
- Financial Dashboard
- KPI Monitoring
- Performance Analysis

The application includes an AI assistant capable of:
